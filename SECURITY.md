# Security

## Supported version

Security fixes currently target the latest source in the `main` branch.

## Reporting a vulnerability

Do not publish private records, access keys, certificates, `.dwr` backups, or reproduction data in a public issue. Contact the repository owner privately and provide the minimum data needed to reproduce the problem.

## Privacy notice

Local JSON, IndexedDB data, and `.dwr` backups are not encrypted by the application. The PWA Screen Lock is not encryption. Use operating-system disk encryption and strong device passwords for sensitive information.
