# 工作经验库 1.3.1｜Windows + iPhone PWA 使用手册

本工具用于记录今日待办、工作经验、方法和可复用思考。Windows 端是主程序；iPhone 端通过 PWA（添加到主屏幕的网站应用）使用。两端在同一个可互访的局域网内自动同步。

## 一、Windows 安装和首次启动

1. 将压缩包完整解压到固定文件夹，不要只复制其中的 `.exe`。
2. 双击 `WORK_EXPERIENCE_LIBRARY.EXE`。
3. Windows 如出现安全提示，选择“更多信息”→“仍要运行”。
4. 防火墙询问时允许“专用网络”。
5. 本版本会创建一套全新的本地数据，不会自动导入其他电脑的数据。
6. 点击窗口右上角“×”不会退出，而是隐藏到 Windows 右下角系统托盘，LAN 同步会继续运行。双击托盘图标可恢复窗口；右键选择 `Exit completely` 才会彻底退出并停止同步。再次双击桌面程序也会唤醒已在后台运行的窗口，不会重复启动。

若提示缺少运行组件，请安装 Microsoft Visual C++ 2015–2022 Redistributable (x64) 后重启程序。

## 二、创建记录

iPhone 有三个可靠的新建入口：

- 顶部搜索框右侧的圆形“＋”；
- 底部导航栏中央的“＋”；
- 首页的“New Record”卡片。

进入新建页后，依次填写 Date、Category、Tags、Related Link（可选）、Attachments（可选）和 Items。Category 可直接输入、修改；多个标签使用英文逗号分隔。

手机操作：Return/换行键在当前 Item 内换行；点击当前 Item 右侧“＋”添加下一项；“－”删除该项；最后点击 Save Record。

iPhone 主屏幕应用采用单击输入逻辑：轻点输入框会直接弹出键盘，不需要双击；双击可点击区域不会再把页面放大，仍保留双指缩放。键盘打开时底部导航会暂时收起，当前输入框自动保持在可见区域；关闭键盘后导航自动恢复。

电脑操作：Enter 添加下一项，Shift + Enter 在当前 Item 内换行。
### 添加附件

在 Attachments 一行点击“Add files”，可选择 PDF、Word、Excel、PowerPoint、TXT、JPG、PNG、GIF、WebP 和 HEIC。每条记录最多 10 个附件，每个不超过 25 MiB。保存记录后，附件本体会写入电脑的独立 SQLite 数据库；手机端先写入 IndexedDB，回到与电脑相同的可互访网络后自动上传。附件使用 SHA-256 校验，传输损坏的文件不会写入数据库。

在记录详情页点击附件可调用系统应用打开；删除附件会生成同步删除标记，防止其他设备把旧文件重新传回。手机离线时可以先添加附件，但必须保留足够的设备存储空间，并在电脑在线时完成同步。

## 三、今日待办

首页 Today To-do 是轻量待办，不等同于正式记录。直接输入并添加，完成后勾选，右侧“×”删除。需要长期保存、分类和复盘的内容，请用“＋”建立正式记录。

## 四、在 iPhone 安装 PWA

1. 电脑和 iPhone 连接同一个可信 Wi-Fi，Windows 程序保持运行。
2. 在 Windows 的 Settings / iPhone PWA 中复制 Setup Guide URL。
3. 必须使用 iPhone Safari 打开该 HTTP 设置地址。
4. 点击“Download Certificate Profile (.mobileconfig)”，在系统询问时点击“允许”。
5. 必须在 8 分钟内打开“设置 → 已下载描述文件”；如果首页没有此入口，则打开“设置 → 通用 → VPN 与设备管理”。
6. 打开名称包含 `Work Experience Library` 和电脑名称的描述文件，点击右上角“安装”，按系统提示确认。显示“未签名”是本地自建描述文件的正常提示；只应安装从自己电脑设置地址下载的版本。
7. 打开“设置 → 通用 → 关于本机 → 证书信任设置”，为 `Work Experience Library Local Root` 开启完全信任并确认。
8. 返回 Safari 设置页面，点击“Open Secure Pairing”。此时不应出现“此连接非私人连接”。
9. 输入 Windows 端显示的 8 位配对码。配对码每 10 分钟自动更新，并在每次成功配对后立即失效；如果提示错误，请直接输入电脑当前显示的新代码。已经配对的设备不会因此掉线。
10. 配对成功后，在 Safari 点“分享”→“添加到主屏幕”。
11. 第一次必须从新建的主屏幕图标再打开一次。新版会尝试自动取回安全会话；如果看到“Pair This Home Screen App”，就在这个主屏幕应用里再输入一次 Windows 当前显示的 8 位配对码。完成后电脑数据会被拉取并合并，以后从主屏幕图标启动即可。

Safari 标签页和主屏幕 PWA 是 iPhone 系统分开的两个本地存储空间，因此“Safari 已经有数据”不代表主屏幕应用也已经配对。这是 iOS 的应用隔离机制，不是数据丢失。两边成功配对同一台 Windows 后，都会通过 Windows 的同一份数据进行同步。

如果“VPN 与设备管理”为空，说明描述文件没有安装成功；请重新用 Safari 下载 `.mobileconfig`，不要从“文件”App 打开裸 `.cer`。如果出现“此连接非私人连接”，不要点击“访问此网站/忽略”，应返回重新安装并信任描述文件。若开启了“失窃设备保护”，请在熟悉地点安装，或按 iPhone 提示暂时处理该限制。

描述文件只包含该电脑的公开根证书，不包含 VPN、MDM、账号、电脑私钥或同步令牌。新版会自动适配不同 iPhone 和 iPad 的刘海、灵动岛、状态栏、横竖屏及底部 Home 指示条。顶部搜索和新建按钮使用系统安全区域；iPad 与窄窗口会自动压缩新建按钮，底部导航贴紧屏幕底部且按钮位于安全区域内。
## 五、两端如何自动同步

自动同步需同时满足：

- Windows 主程序正在运行；
- 电脑与 iPhone 当前在同一个可互访局域网；
- Windows 网络类型为“专用网络”，防火墙允许本程序；
- 路由器未开启访客隔离或 AP Isolation。

记录和附件采用本地优先方式：离线仍可编辑；重新满足网络条件后继续同步。1.2.0 起，同步返回内容会与手机当前记录在同一个本地事务中比较，手机在同步过程中继续编辑也不会被旧响应覆盖；多台手机同时连接时，电脑会按顺序合并并一次落盘。以后两台设备一起换到另一个 Wi-Fi 也能使用，但电脑局域网 IP 可能变化。此时在 Windows 设置页查看新的手机访问地址，用 Safari 打开一次，再进入 PWA。通常不需要重装证书。

如果主屏幕应用显示“Pair This App”，或点击 LAN Sync 后进入配对页，说明这个主屏幕应用还没有自己的同步密钥。保持 Windows 程序运行，输入电脑当前显示的 8 位配对码一次即可。同步成功后，主屏幕应用会显示与电脑一致的数据；断网期间新增内容先保存在手机本地，恢复到同一可互访网络后再点击 Sync Now 或等待自动同步。

这不是云同步。设备不在同一局域网、电脑关机或程序退出时，无法即时互传。恢复条件后把 PWA 切回前台并等待片刻，必要时刷新。

## 六、页面功能

- Timeline：按日期查看记录；
- Favorites：查看收藏，卡片布局与时间线一致；
- Search：搜索内容、分类和标签；
- Categories / Tags：按分类或标签筛选；
- Trash：查看已删除内容；
- Settings：手机连接、同步、导入导出和安全设置。

## 七、备份和换电脑

建议定期在设置页导出备份，另存到安全位置。当前 `.dwr` 导出包含记录、分类和标签，不包含附件二进制；附件保存在 `attachments.sqlite`，换电脑时可让两台电脑在同一网络下通过 LAN 同步附件，或在程序完全退出后连同应用数据目录一起备份。在另一台电脑上需要全新数据时，直接解压并启动，不要导入旧备份；需要迁移时再使用导出/导入。

请勿把程序目录当作唯一备份，也不要在程序运行中手工删除数据文件。

## 八、常见问题

### 顶部搜索框被时间、电量或灵动岛覆盖

通常是旧版 PWA 缓存。先从 iPhone 多任务界面上滑完全关闭应用，再重新打开。仍未更新时，用 Safari 打开 Windows 设置页提供的地址并刷新一次，然后回到主屏幕应用。

### 双击后页面放大，或者点击输入框键盘不出现

1. 完全关闭主屏幕 PWA 后重新打开，让新版离线缓存生效。
2. 以后直接单击输入框，不需要双击。所有手机输入框均使用适合 iPhone 的字号，键盘打开时底栏会自动隐藏。
3. 如果仍是旧行为，用 Safari 打开电脑提供的安全配对地址并刷新，然后再次关闭、重开主屏幕 PWA。必要时删除旧主屏幕图标后重新添加。

### 看不到“＋”或无法新建

新版在顶部右侧、底部中央和首页均有新建入口。确认电脑运行的是本压缩包版本，并按上一条刷新 PWA。

### VPN 与设备管理为空，或者出现“此连接非私人连接”

这表示根证书描述文件没有成功安装和信任。请使用 Safari 从 Setup Guide 重新下载 `.mobileconfig`，在 8 分钟内到“设置 → 已下载描述文件”安装，再到“关于本机 → 证书信任设置”开启完全信任。输入 8 位配对码不能代替证书；不要通过“忽略/访问此网站”绕过警告。

### 手机连接不上
依次检查：同一 Wi-Fi、Windows 程序正在运行、网络为专用、防火墙已允许、手机能打开设置页给出的地址。公司、酒店和访客 Wi-Fi 常禁止设备互访，可改用普通家庭路由器或允许局域网互访的热点。

### 换 Wi-Fi 后不同步

在 Windows 设置页取得当前网络的新地址，用 iPhone Safari 打开一次。电脑和手机必须位于同一可互访网络。

### 页面还是旧界面

完全关闭 PWA 后重开；仍无效则在 Safari 刷新手机访问地址。新版离线缓存会在重开后接管。

### 底部按钮被 Home 指示条遮挡

本版已让导航贴底，同时自动加入底部安全区。如果仍显示旧的悬浮导航，说明手机还在使用旧缓存，请按上一条刷新。

## 九、安全说明

仅在可信局域网使用同步。配对码用于限制未授权访问，但不等同于端到端加密。电脑数据文件、手机离线数据和导出的备份均不是加密保险箱；不要在公共 Wi-Fi 开放同步，也不要保存密码、银行卡密钥等高敏感信息。

## 十、压缩包完整性

请保留解压后的全部文件和子目录。主程序、Flutter 运行库、PWA 资源及本手册共同构成完整版本；仅复制 `.exe` 可能导致无法启动或手机仍显示旧页面。
## 十一、1.2.0 风险修复说明

- 电脑端所有 LAN 数据修改与磁盘保存按顺序执行，避免多个设备同时同步时争用同一个临时文件。
- 一次手机同步先在内存中完整合并，再统一保存；外部网址、端口、证书和 API 均保持兼容。
- 手机端使用 IndexedDB 原子事务合并远端记录，同步期间新输入的内容不会被旧响应静默覆盖。
- “清空回收站”会保留同步删除标记，避免记录被其他设备重新同步回来。
- localStorage 降级模式会继续触发同步，但容量较小，应定期导出备份。
- 配对码每 10 分钟和每次成功配对后自动更新，已配对设备的访问密钥保持有效。
- PWA 内嵌脚本使用随机 CSP nonce，降低脚本注入风险。
## 十二、1.3.0 附件功能说明

- 记录编辑页新增独立 Attachments 行，电脑、iPhone 和 iPad 均可添加受支持文件。
- 电脑附件本体保存在独立 `attachments.sqlite` 数据库，不写入原有 `library.json`，现有记录和通讯接口保持兼容。
- 手机端使用 IndexedDB Blob 离线保存附件；同一局域网重新可用时通过新增 HTTPS 附件接口自动同步。
- 上传、下载均核对大小和 SHA-256；文件名、扩展名、MIME类型和单文件大小均经过校验。
- 删除附件或永久删除记录会保留同步墓碑，避免其他设备把旧附件恢复回来。
- 这仍然是 LAN 同步，不是云盘；电脑关机或设备不在同一可互访网络时，附件只保存在当前设备，等待下次同步。


## 十三、1.3.1 iPhone 触摸与键盘修复说明

- 页面级使用 `touch-action: manipulation`，取消控件双击放大和点击延迟，同时保留双指缩放。
- 手机端输入框、搜索框、密码框、分类和 Item 文本框统一使用 16px 字号，避免聚焦时页面自动放大。
- 使用 Visual Viewport 识别软键盘；键盘出现时收起底部导航并将当前输入框滚动到可见区域。
- 底部导航整体高度和安全区空白缩小，图标更靠近屏幕下边界，但仍为 Home 指示条保留空间。
- PWA 离线缓存升级到 v11，重新打开主屏幕应用后会自动替换旧界面。
